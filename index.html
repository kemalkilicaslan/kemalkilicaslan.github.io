Kaprekar Constant with Python Programming

This project implements, using only Python code, the process of reaching 6174, the constant discovered by D.R. Kaprekar in 1949, from any four-digit number with at least one differing digit, in at most 7 steps, by repeatedly applying simple arithmetic operations. For three-digit numbers, this number is 495.

Real-Time Colonoscopy Polyp Segmentation System

Polyp Alarm Demo
False Positives Before Polyp-Free Training
Low-Contrast Failures

Images: HyperKvasir (CC BY 4.0) and CVC-ClinicDB (© Hospital Clinic / Computer Vision Center, Barcelona; research and education only), with model outputs added.

This project implements real-time polyp segmentation for colonoscopy video using a PyTorch U-Net, a frame-quality check, and an IoU tracker that alarms after three consecutive frames. Training on polyp-free frames cuts false alarms on normal colon from 30.6 to 6.2 per minute, and the model scores 0.853 Dice on data from another hospital.
